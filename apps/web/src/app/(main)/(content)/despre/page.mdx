# Despre

SICAP.ai este un motor de cautare pentru baza de date a licitatiilor publice si achizitiilor directe.
Datele sunt preluate din portalul guvernamental de licitatii publice [e-licitatie.ro](https://e-licitatie.ro/) în baza [Licenței pentru Guvernare Deschisa](https://data.gov.ro/base/images/logoinst/OGL-ROU-1.0.pdf) v1.0 

Contractele de licitatii publice si achizitii directe se actualizeaza zilnic iar in prezent sunt indexate <TotalsDisplay />.

Profilul fiecărei companii include și date de la Oficiul Național al Registrului Comerțului (ONRC), precum activitățile autorizate (CAEN), sucursalele și istoricul înregistrărilor, împreună cu situații financiare anuale de la Ministerul Finanțelor Publice (MFP): cifră de afaceri, profit, venituri, cheltuieli, capitaluri, datorii și active. Aceste informații sunt preluate din portalul de date deschise [data.gov.ro](https://data.gov.ro/) și pot fi incomplete sau eronate; afișăm doar ceea ce există în sursele oficiale.

Scopul acestui proiect este de a aduce mai multa transparenta pentru cheltuielile publice si de a putea detecta eventualele suspiciuni de frauda cu ajutorul comunitatii si inteligentei artificiale.

Codul este open source pe github la adresa
[github.com/ciocan/sicap.ai](https://github.com/ciocan/sicap.ai)

Pentru analiza avansata unde se pot raspunde la intrebari de genul - Cati lei au fost cheltuiti in Brasov in ultimii 3 ani pe lucrari de constructii de drumuri, sau care este lista cu toate companiile din judetul Ialomita ordonata dupa valoarea contractelor,
exista un proiect separat la adresa [github.com/ciocan/sicap-explorer](https://github.com/ciocan/sicap-explorer)

# Integreaza

## Widget Integrabil

Poți afișa ultimele achiziții publice ale oricărei autorități contractante direct pe site-ul tău folosind widget-ul nostru embed. 
Află mai multe pe pagina [Widget Integrabil](/integreaza).

## API Public

Pentru integrări personalizate și acces programatic la date, este disponibil un API public REST. 
Documentația completă OpenAPI este disponibilă la [api.sicap.pro/v1/openapi](https://api.sicap.pro/v1/openapi).

## Server MCP

Poți interoga datele de achiziții publice direct din Claude sau din alți agenți AI compatibili Model Context Protocol (MCP), autentificându-te cu contul tău SICAP.ai, fără să copiezi vreun token.
Află cum să configurezi conectorul pe pagina [Conector MCP](/mcp).

Ai sugestii sau recomandari? Foloseste acest [link](https://github.com/ciocan/sicap.ai/issues)
